SHARES السمع البصري للطوارئ — Arabic lip reading for emergencies

When audio fails — noise, glass, underwater — lips are the only channel left. SHARES reads Arabic emergency words from silent video, in real time.

  • typecomputer vision · real-time
  • rolesolo project
  • headline76% top-1 accuracy

the problem

Every major lip-reading benchmark — LRW, GRID — is English. Building Arabic lip reading meant collecting and labeling video data from scratch for the target emergency vocabulary.

And lips don't carry meaning in a single frame: a word is a sequence of subtle movements over time. The model has to track what the lips look like and how they move — simultaneously.

how it works

  1. Collect the dataset that didn't exist

    Recorded and labeled native Arabic speakers saying emergency words, then augmented with horizontal flips, speed perturbation, and brightness variation for robustness.

  2. Isolate the lips

    MediaPipe face-landmark detection crops and normalizes the lip region every frame — removing background variation so the model sees mouth movement, nothing else.

  3. Factorize space and time — R(2+1)D

    3D convolutions decomposed into a 2D spatial conv followed by a 1D temporal conv: fewer parameters, same power to model movement across frames.

  4. Run it live

    A sliding window over live webcam frames feeds the model, which emits a class label and confidence score at every step — real-time recognition, not offline processing.
