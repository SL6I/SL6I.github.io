Reject Me First An adversarial AI committee for startup ideas

Most startup feedback is polite. This committee of adversarial AI agents finds the failure modes before the market does.

  • typemulti-agent system
  • rolesolo project
  • headline3 adversarial agents + synthesis

the problem

Investors pass without saying why. Friends encourage without knowing the domain. And a single LLM asked to "critique my startup" optimizes for completeness, not depth — it covers every angle shallowly, which is exactly what investors don't do.

Useful pre-mortem feedback requires agents that are adversarial by design — each one committed to finding failure modes in its own domain.

how it works

  1. Idea intake — no template

    Submit the concept in plain natural language. The system parses intent, target market, and core value proposition automatically.

  2. The market agent attacks

    Challenges addressable market size, competitive landscape, and timing: who else is doing this, why now, who actually pays?

  3. The technical agent attacks

    Probes build complexity, technical risk, and the gap between what's described and what's buildable — flagging over-engineering, under-scoping, and dependency risks.

  4. The financial agent attacks, then synthesis

    Stress-tests revenue assumptions, burn rate, and unit economics. A synthesis layer aggregates the sharpest critiques into a final verdict — with the strongest counter-arguments highlighted, so it's a sparring partner, not a firing squad.
